# Landing Page - Plan Corretagem

Landing page institucional desenvolvida para a **Plan Corretagem**, com foco em apresentar os planos de saúde disponíveis e facilitar o primeiro contato comercial via WhatsApp.

Projeto criado como prática de front-end, aplicando HTML, CSS e JavaScript em um caso de uso real.

## 🔗 https://github.com/Fabjinkings/landing-page-plan-corretagem/](https://fabjinkings.github.io/landing-page-plan-corretagem/)


## ✨ Funcionalidades

- **Formulário de cotação** integrado ao WhatsApp: o visitante preenche nome, telefone, idade e tipo de plano, e o site monta automaticamente uma mensagem e abre o WhatsApp com os dados preenchidos.
- **Seção de operadoras parceiras clicável**: cada logo (Hapvida, Bradesco, Amil, SulAmérica, Proasa e Porto Dias) abre o WhatsApp já com uma mensagem perguntando sobre aquele produto específico.
- **Menu mobile responsivo** com abertura/fechamento via JavaScript.
- **Botão flutuante de WhatsApp** fixo na tela para contato rápido.
- Layout responsivo, adaptado para desktop e mobile.

## 🛠️ Tecnologias utilizadas

- **HTML5** – estruturação semântica do conteúdo
- **CSS3** – estilização, responsividade e efeitos de hover/transição
- **JavaScript (vanilla)** – manipulação de DOM, eventos de clique e teclado, geração dinâmica de links `wa.me` com mensagens personalizadas via `encodeURIComponent`

## 📁 Estrutura do projeto

```
├── index.html      # Estrutura da página
├── style.css       # Estilos e responsividade
├── script.js       # Interatividade (menu, formulário, cliques nas logos)
└── img/            # Logos e imagens utilizadas no site
```

## 🚀 Como executar localmente

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente no navegador.

Não há dependências ou processo de build — é um projeto front-end puro (HTML, CSS e JS).
